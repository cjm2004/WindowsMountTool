=== 产品形态（两个 exe）===
1. 安装 exe（安装包）：一次性的安装程序
2. 配置 exe：安装后放在安装目录下，日常可视化配置与管理用

=== 一、安装 exe 的流程 ===
1. 用户在新电脑上双击 exe 执行安装，进入安装界面（向导式：欢迎 → 选安装目录 → 环境检测 → 安装 → 完成）
2. 安装过程中检测环境：逐项检查 WinFsp、alist、rclone 等组件是否已安装/可用，界面上逐项显示检测结果
3. 缺失的组件自动安装：
   - alist、rclone：优先释放内嵌的工具包版本（v3.63.0 / v1.75.0）到安装目录 tools/ 下
   - WinFsp：静默安装（官方安装程序支持静默参数）；若未内嵌则从官网下载——下载前先明确提示用户、显示进度、设置合理超时，失败可重试或允许手动指定本地安装包
   - 已存在的组件跳过，不重复安装
4. 【关键】WinFsp 安装完成后必须显著提示"需重启电脑一次才能激活盘符能力"，提供"立即重启 / 稍后重启"选择；未重启前不得谎报挂载成功
5. 安装完成后，安装目录下有配置执行 exe，并创建桌面/开始菜单快捷方式
6. 安装目录默认放非系统保护目录（如 D:\，可改），路径避免中文与空格；若用户坚持装到受限目录（如 Program Files），数据/日志/配置改放用户可写目录

=== 二、配置 exe：可视化逐步引导 ===
1. 点击配置 exe 进入配置可视化逐步引导页面（分步向导，不是一屏堆满所有设置）
2. 新建挂载配置时，可选的配置类型（保留可扩展性）：
   a. WebDAV：填服务器地址、端口、账号、密码、挂载盘符
   b. 中国移动网盘（和彩云/139 邮箱云盘）：按工具包指引进 Alist 添加对应存储驱动；界面需引导用户去网页登录抓包获取 authorization token 并填入
   c. Alist（OpenList）目录：连接已有 Alist/OpenList 服务器的目录（填地址 + 账号密码 + 子路径）
   d. 其他类型（预留扩展）
3. 每条配置可设置：挂载盘符（默认从 Z: 起，可改，自动避开已占用盘符）、卷标、缓存模式等参数
4. 配置保存到本地；密码类字段必须经 `rclone obscure` 加密后落盘，绝不存明文
5. 配置列表页：对每条配置可逐一点击操作：
   - 挂载：执行该条挂载，以"此电脑"中真实盘符出现且可读写为成功标准
   - 取消挂载：安全卸载对应盘符、结束对应进程
   - 删除：清理该配置及其关联挂载与自启项
   - 其他操作（查看状态/日志、编辑等，可扩展）
6.（可选加分项，来自工具包）本地回收站目录：删除文件先进回收站不真删

=== 三、挂载核心逻辑（必须吸收工具包脚本的防御性设计）===
- 幂等：盘符已存活则直接跳过，不重复挂载
- 挂载前先杀掉一切残留的 rclone 进程，避免多实例抢同一盘符
- 挂载成功的判断必须基于真实盘符出现（如 [System.IO.DriveInfo]::GetDrives()），不能只看进程在跑
- 本地 Alist 就绪判断：HTTP GET http://127.0.0.1:5244/ 返回 200；未就绪先杀旧进程再拉起、最多等 60s
- rclone 挂载参数参考工具包模板（--vfs-cache-mode full、--no-modtime、--dir-cache-time、卷容量显示等），不要加 --network-mode
- 看门狗自愈：周期巡检（如每 3 分钟）端口 + 盘符，异常自动调用挂载逻辑修复，带 180s 冷却防止狂重启
- 维护开关：data/ 下放 MAINTENANCE 文件则暂停自动挂载与自愈
- 日志：挂载日志 / rclone 运行日志 / 看门狗日志分开记录，单文件超 200KB 自动裁剪保留末 400 行
- 涉及驱动与计划任务的操作需要管理员权限：程序需有 UAC 提权处理（manifest 要求管理员，或按需提权并明确提示）

=== 四、开机自启挂载等功能 ===
- 提供"开机自动挂载"功能开关：开启后登录系统即自动挂载所有已启用的配置（计划任务 ONLOGON + 最高权限 + 隐藏窗口，或服务等价机制）
- 开机自启同时启用看门狗巡检（断线自愈）
- 用户可随时在配置界面开/关此项；删除配置或卸载时同步清理自启项

=== 五、强制约束（工具包血泪验证，必须全部遵守；遇到对应现象直接按解法处理，不要反复试错）===
A. WinFsp 安装后必须重启电脑一次才能真正激活"本机会话创建盘符"的能力；一切"挂载成功"的判断都要基于真实盘符出现
B. rclone 连接 Alist 的密码必须用 `rclone obscure <密码>` 加密后写入配置文件，不要内联明文、不要 base64（会认证失败 401）
C. rclone 挂载不要加 --network-mode（本机网络提供者 DLL 未就位，加了反而挂不出盘符）
D. 启动 rclone 前必须先杀掉一切残留的 rclone 进程
E. 检测盘符存活用 [System.IO.DriveInfo]::GetDrives() 安全检查，不要用 Get-ChildItem "Z:\"（盘符不存在时会抛穿透 try/catch 的终止异常把脚本打崩）
F. 生成的 PowerShell 脚本必须 CRLF 行尾（LF 会让 PowerShell 5.1 括号错位报"意外的标记 }"）
G. 计划任务动作路径若含中文目录，写完后用 UTF-8 复查真实路径；ascii 落盘显示的 ?? 是假象
H. Alist 首次启动后要立即设置 admin 密码（否则 WebDAV 匿名/空密码会被 401 拒绝），并同步更新 rclone 配置的加密密码
I. 回收站等 Local 存储指向的目录必须先 mkdir 出来，否则该存储加载失败报 not found
J.（新增）所有联网下载动作：先明确提示用户再执行、显示进度、设置合理超时，失败提供重试与手动兜底方案
